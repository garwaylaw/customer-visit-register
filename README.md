# 客户拜访登记助手 / Customer Visit Register

面向支持 SKILL.md 的 AI 助手的通用工作流：识别客户拜访转写，匹配已有客户，展示结构化方案，用户确认后新增或更新客户登记表，拜访历史只追加。

## 支持范围

仅理解和填写以下14类字段及其同义字段：客户名称、地区、集散地、客户类型、拜访日期、拜访类型、跟进人员、门头照片、拜访信息、综合文本备注、合作意向、意向产品、物料、竞品品牌。按实际类型、选项和内容理解，不要求各用户统一表头。其他列不修改。

平台可为腾讯智能表格、飞书多维表格、WPS、Excel或其他表格。**本仓库提供技能规则，不内置各平台SDK，也不提供账号或连接权限。** 需要使用者环境已有的对应连接器、CLI、表格技能或受支持浏览器工具。没有写入通道时仍可准备草案，但不能自动入表。各平台真实写入尚未实测。

不负责音频转写，请提供已经转写的文字。

## 安装与调用

审核文件后，将 `skills/customer-visit-register/` 整个目录复制到助手的技能目录；Codex默认目录为 `~/.codex/skills/`。这是手动安装说明，本仓库不会执行安装或授权操作。

调用示例（虚构）：

```
使用 $customer-visit-register
客户拜访管理表：我的客户登记表链接
我在表中的填表人名称：李明
拜访时间：2026年9月25日
转写：去了青桥镇青木定制，老板想试B铰链，下次带样品。
请先查找客户并给我确认单，确认后再写入。
```

首次会提醒提供客户拜访管理表地址、用户在表中的填表人名称，并确认目标子表和字段用途；以后按目标表的本地配置复用，字段或用户身份变化时重新核对。每次写入仍需确认具体客户和变更。历史只追加，没说的信息不清空。

## 包内容与验证

- `skills/customer-visit-register/SKILL.md`：入口。
- 技能内 `references/`：14类字段、平台路由、客户匹配、确认提交、配置示例及22个虚构评估场景。
- `references/keyword-corrections.md`：内置误词候选、Obsidian知识库规范词及持续积累规则。
- 技能内 `agents/openai.yaml`：Codex展示信息。
- `tools/validate_package.py`：Python标准库离线检查，不会安装依赖、联网或写入业务表。

运行 `python3 tools/validate_package.py` 检查文件与引用，再按 `references/evaluation.md` 验证实际行为。结构校验不能证明在线写入可用。

运行时可在当前项目 `.customer-visit-register/keyword-corrections.local.md` 持续积累经用户确认的勘误。公共词库不保存客户转写或隐私信息，也不会自动提交到GitHub。
