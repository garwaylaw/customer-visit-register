# 平台连接：业务通用，读写能力按环境验证

本文件是路由规范，不是已经实现的多平台API。使用已有连接器、CLI、技能或受支持浏览器工具。平台工具不存在时不编造命令或请求参数；需要安装/授权时先说明并请用户确认。

## 通用能力契约

下列名称仅表示逻辑操作，不是可直接调用的工具：

```
describe_target -> 平台/文件/子表ID、字段ID/名称/类型/选项/只读标记
search_customers -> 候选、检索范围、分页完整性
read_record -> 完整原值、稳定ID、版本（若有）
create_record -> 返回新记录ID
patch_record -> 只修改指定字段，条件版本（若支持）
read_record -> 回读验证
```

执行前确认实际工具能完成哪些操作。只读权限不证明可写；接口200不证明业务成功。检查合法响应、目标资源和权限。读取不得局限于当前筛选视图；分页至无下一页，或明确验证搜索覆盖全表。

### 飞书/Lark 多维表格

环境有 `lark-base` 或对应连接器时按其实际技能/schema操作；鉴权问题按需查看现有鉴权说明。先识别Base和子表，再读字段、搜索记录、按稳定record ID写入。人员/选项不能用猜测ID。

普通飞书电子表格使用其表格工具，不当作多维表格。只读取完成14类字段映射、客户查重和已批准修改所需的数据。

### 腾讯文档、智能表格、企业微信文档

先区分个人腾讯文档与企业微信资源。企业微信工具只有在产品、资源及授权匹配时可用，不能将所有腾讯链接交给企业微信接口。

优先官方授权API或已有连接器，其次受支持浏览器。公开页面的预加载数据可帮助读取，但须核验字段映射、分页与行数；预览不等于全表。读取接口成功不能推导写接口存在，不固定未公开接口、临时cookie或屏幕坐标。

接口拒绝访问时不绕过权限；使用正常授权路径，权限变更先确认。

### WPS

识别WPS在线电子表格、多维表格、桌面工作簿或本地文件。已有官方API/连接器就按当前文档操作；否则用受支持浏览器检查实际读取/编辑能力。只有查看链接、没有可写通道时继续输出草案并明确阻塞。

修改下载副本不等于更新云端原表。回传/导入/覆盖需要具体说明目标和影响后确认，不能默默替换整份在线文件。

### Excel、本地文件及其他在线表格

本地Excel/CSV优先使用本地表格技能与工具，不为处理文件上传到第三方服务。确认前只读；确认后默认生成新副本，用户明确要求原地修改才备份后执行。保留未修改列、格式和工作簿结构；工具无法无损保存时先说明限制。

在线Microsoft 365、Google Sheets等使用环境已连接工具。普通电子表格先确定表头和数据区，不能把行号当稳定客户ID；排序、插行后需重新定位客户。无法唯一定位就停止。

## 不可用的路径

缺少写入能力不妨碍生成可确认的提取结果，但必须区分“待写入”和“已写入”。不得索取浏览器cookie、读取凭据数据库、私自安装程序或声称全部平台已经实测。

平台限制导致某个范围外列必填时只报告该阻塞，用户处理后再重试；不扩大本skill的14类业务字段范围。
